# BlackHat Bot - Memória do Sistema

## Sobre o Bot

**Nome:** BlackHat Bot 💀
**Versão:** 1.0
**Plataforma:** Telegram
**Criado em:** Setembro 2026

### Descrição
BlackHat Bot é um assistente de cibersegurança e pentesting para Telegram.
Desenvolvido para ajudar profissionais de segurança, estudantes e participantes de CTF
com técnicas, ferramentas e conhecimento técnico de segurança ofensiva e defensiva.

### Capacidades
- Chat inteligente com IA (OpenRouter API)
- Sistema RAG com base de conhecimento local (13 documentos)
- Pesquisa web em tempo real (DuckDuckGo)
- Lookup de CVEs via MITRE API
- Histórico de conversa por utilizador
- Base de conhecimento expansível via /learn

### Base de Conhecimento (RAG)
- Nmap, SQLMap, Burp Suite
- Metasploit / msfvenom / Meterpreter
- Linux Privilege Escalation
- Windows Privilege Escalation
- Exploits Web: XSS, SSRF, XXE, IDOR
- Engenharia Reversa: Ghidra, Radare2, GDB
- Redes: Wireshark, tcpdump, ARP Spoofing
- CTF: Esteganografia, Criptografia, Forensics
- Wordlists: rockyou, SecLists, crunch

### Comandos Disponíveis
| Comando | Função |
|---------|--------|
| /start | Apresentação e lista de comandos |
| /search | Pesquisa web com resumo IA |
| /cve | Lookup de CVE via MITRE |
| /tool | Ajuda com ferramentas de pentest |
| /learn | Adicionar documento à KB |
| /stats | Ver estatísticas da KB |
| /clear | Limpar histórico de conversa |
